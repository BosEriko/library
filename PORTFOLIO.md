# Library

Library is a search service for anime, manga and games. Type a title once and get matching results for all three, then open any of them to see a full profile. It works as a website for browsing and as a public API for other apps.

---

## What it does

- Search anime, manga and games at the same time, with results grouped by type
- Open any result to see its cover, banner, synopsis, score, genres and release details
- See details that fit each type: episodes and studios for anime, chapters and authors for manga, platforms and developers for games
- Get every title in the same shape, so anime, manga and games can be handled the same way

## For developers

- A public, read-only JSON API with a search endpoint and a profile endpoint
- A built-in documentation page that explains every endpoint, field and error
- Partial results when one data source is unavailable, instead of a failed search

## Fast and up to date

- API responses are cached at the edge for a week
- Titles that have been opened are kept and refreshed monthly
